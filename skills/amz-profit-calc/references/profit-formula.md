# 利润公式与隐赚算法（amz-profit-calc）

> 融合 seller-agent scripts/calculator.py + methodology-cards（invisible-profit / lightweight-profit / pricing-position）。

## 一、Amazon FBA 单均 P&L

```
单均毛利 = 售价 − 采购成本 − FBA配送费 − 平台佣金 − 广告成本
毛利率   = 单均毛利 / 售价 × 100%
```

- **售价**：ProductRequest.SalesPrice（扣券后实付）
- **采购成本**：含头程到 FBA 仓；中国跨境卖家按 1688 价估算
- **FBA 配送费**：ProductRequest.FbaFee（优先用真实值）；无真实值时粗估 `max(3.5, kg×2.5+1.5)`
  - FbaDetetail 示例 `["475","1-9:5","10-12:15"]` = 配送 $4.75 + 1-9月仓储 $0.05 + 10-12月仓储 $0.15
- **平台佣金**：ProductRequest.PlatformFee（多数类目 ~15%）
- **广告成本**：默认按售价 15% 假设（`[ASSUMED]`），成熟期可调到 8-12%，新品期 20%+

## 二、退货侵蚀敏感性

每退一单损失 = 该单利润 + 退件处理费（~$3.5，含不可售/弃置）。

```
退货后单均净利 = 单均毛利 − (单均毛利 + 3.5) × 退货率
```

| 退货率 | 含义 |
|---|---|
| 3% | 多数标品 |
| 5% | 常见均值 |
| 10% | 服装/鞋类/尺码相关 |
| 15%+ | 轻量品实际可能负利润，轻量利润指数不含退货，务必叠加 |

## 三、盈亏平衡

```
盈亏平衡月销量 = 月固定成本 / 退货后单均净利
盈亏平衡日销量 = 盈亏平衡月销量 / 30
```

默认月固定成本 $500（仓储/软件/人工摊薄）。单均净利 ≤0 时无法盈亏平衡。

## 四、隐赚指数（HPI）

Sorftime 官方 HPI 是 MCP 专属复合推荐分（`potential_product`），综合需求热度/供给稀疏/利润/评论壁垒/品牌真空/增长可持续/场景可描述/复杂度。

本地 `profit_calculator.py` 给的是**代理分**（0-100），仅用于相对排序：

```
HPI代理分 = 毛利(40) + FBA费占售价比越低越高(30) + 越轻量越高(30)
```

⚠️ 代理分 ≠ 官方 HPI，不能跨类目直接比较，只在同类目内排序参考。

## 五、轻量利润效率

```
利润效率 = (毛利率 × 月销) / FBA费
```

- 比"绝对利润"更好用：$10×100=$1000 vs 效率 (50%×$20×100)/$4 ≈ 250
- 典型轻量甜区：重 200-500g、FBA 费 $3.0-4.5、售价 $15-25、毛利率 50%+
- 灰区：500-600g 被传统"500g 上限"误杀，但 FBA 费只差 $0.5-1，售价高就盖得住

## 六、定价位置（Price Band）

```
价格带机会分 = 该带销量份额 ÷ 该带 ASIN 密度 × (1 − 该带均评论数/1000)
```

- 用 ProductSearch 按 $5/$10 分桶算各带销量占比与 ASIN 密度
- 甜点在中段偏上：销量密度高、ASIN 密度适中、均评论数低（新进入者可超）
- FBA 费阶悬崖：定价在费阶边界（如刚 $19.99 触发更高阶）可能比低一档更不赚

## 七、数据置信标签

| 标签 | 用于 |
|---|---|
| `[VERIFIED]` | ProductRequest 直接返回的价格/FBA费/佣金/月销 |
| `[ESTIMATED: formula]` | 本地 P&L、盈亏平衡、代理 HPI |
| `[ASSUMED: industry]` | 广告占比 15%、退货率 5%、月固定成本 $500 |
| `[UNAVAILABLE]` | 字段缺失（如某类目无法估算销量） |
