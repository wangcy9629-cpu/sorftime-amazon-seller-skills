安装步骤

1

安装 Claude Code

确保已在系统中安装 Claude Code CLI 工具

# 验证安装
claude --version

未安装？访问 claude.ai/download

2

复制 Skill 文件

将 Skill 文件复制到 Claude Code 的 skills 目录

# 创建目录（如果不存在）
mkdir "%USERPROFILE%\.claude\skills\sorftime-shop-health-monitor"
# 复制文件
copy "店铺六维监控自动化-SKILL.md" "%USERPROFILE%\.claude\skills\sorftime-shop-health-monitor\SKILL.md"
3

配置 Sorftime MCP

确保 Claude Code 已配置 Sorftime MCP 工具

MCP 配置需在 Claude Code 设置中完成，请联系 Sorftime 获取配置指引

4

一键启动（可选）

双击运行批处理文件自动完成安装并启动

双击运行：一键启动-店铺六维监控.bat

配置参数

首次使用时，在 Claude Code 中配置以下参数：

{
  "核心ASIN": ["B08XXXXXXX", "B08YYYYYYY"],
  "主营类目NodeID": "123456789",
  "品牌关键词": ["YourBrand", "YourBrandName"],
  "监控站点": "US",
  "预警阈值": {
    "自然流量占比": 0.5,
    "可售天数": 14,
    "榜单变化率": 0.3,
    "退货率超标": 0.02
  }
}

核心ASIN

需要监控的主力产品ASIN，可配置多个

类目NodeID

主营类目的亚马逊节点ID，用于竞争分析

品牌关键词

品牌名称的不同写法，用于监控品牌词搜索

预警阈值

触发不同级别预警的临界值

使用教程

启动 Claude Code 后，使用以下指令调用监控系统：

SOP 1

每日自动化健康扫描

建议每日05:00自动执行，扫描流量、库存、竞争三个核心维度

# 指令
claude "/sorftime-shop-health-monitor 运行每日扫描"

监控项：

  • 流量结构健康度（自然流量占比）
  • 库存健康度（可售天数预警）
  • 竞争格局突变检测（Top3变化率）
SOP 2

每周策略优化报告

建议每周日执行，分析类目竞争格局、流量词效能、季节性预判

# 指令
claude "/sorftime-shop-health-monitor 生成周报"

报告内容：

  • 市场环境变化（搜索量、新进入者）
  • 自身表现分析（排名稳定性、品牌词增长）
  • 下周行动清单（优先级排序）
SOP 3

月度深度诊断报告

建议每月1日执行，六维评分卡 + 风险预警 + 下月目标设定

# 指令
claude "/sorftime-shop-health-monitor 生成月报"

输出文件：

  • 月度诊断报告.md（详细分析）
  • 风险预警面板.json（红黄绿灯状态）
  • 下月目标设定.md（可执行KPI）

输出文件

所有报告将自动生成到以下目录结构：

./output/
├── daily-report-YYYYMMDD.md          # 每日健康日报
├── weekly-report-weekNN.md           # 每周策略报告
├── monthly-report-YYYYMM.md          # 月度深度诊断
└── alerts/
    ├── inventory-warning.json        # 库存预警
    └── competition-alert.json        # 竞争预警

常见问题

Q: 如何获取类目NodeID？

A: 使用 Sorftime 的类目搜索功能，找到主营类目后查看节点ID；或在亚马逊类目页面URL中提取 node 参数。

Q: 可以监控多个ASIN吗？

A: 可以，在配置参数的"核心ASIN"中添加多个ASIN即可，系统会自动遍历监控。

Q: 如何设置定时自动执行？

A: Windows 用户可使用任务计划程序(Task Scheduler)设置定时任务；或使用一键启动脚本中的示例命令。

Q: 预警阈值可以自定义吗？

A: 可以，在配置参数的"预警阈值"中调整各项临界值，适配你的运营策略。
