一键市场
amz-market-analysis
11 维评分判断类目值不值得进、价格带甜区、品牌垄断与变体缺口。
最少输入：品类名 或 类目 nodeId
一键找货
amz-supply-chain
1688 找工厂/货源、候选对比、Amazon↔1688 跨平台价差。
最少输入：产品名 或 目标 ASIN（domain=601）
一键VOC
multi-asin-voc-analysis
8-12 个竞品 ASIN 评论深挖，出「谁能打、打哪里、凭什么」击破作战包。
最少输入：品类名 + 竞品 ASIN 清单
一键广告
amz-ad-planning
纯 Sorftime 关键词数据出活动结构、预算分配、出价与否定词策略。
最少输入：目标 ASIN 或 关键词表
一键守盘
sorftime-shop-health-monitor
自有店铺六维健康度：每日扫描 / 每周策略 / 月度深度诊断。
最少输入：自有 ASIN + 类目 nodeId + 预警阈值

预设流水线 · 一条命令跑一串

流水线 怎么喊 环节序列 适合
P1 类目可行性 一键跑类目可行性：XXX 市场分析 → 找货源 → 算利润 有品类名，评估要不要进
P2 竞品击破 一键击破这批竞品 多ASIN VOC → 广告规划（+Listing） 已锁定竞品 ASIN 清单
P3 新品启动 一键新品启动：XXX 市场分析 → 找货源 → 广告规划 确定要上，出启动方案
P4 守盘周报 一键守盘周报 店铺健康度（周策略） 自有店铺例行巡检
P5 全链路 一键全流程：XXX P1 + P2 + P4 合并 完整跑一遍（消耗最大，会二次确认）

执行方式

  1. 自动跑体检：检查子 skill 是否齐 + Sorftime 通道是否可用。
  2. 路由：按你的口令或语义命中对应子 skill。
  3. 加载并执行：实际读取子 skill 的 SKILL.md，按其规范跑，不凭记忆复述。
  4. 串联：中间产物落盘到 _work/amz-oneclick/<run-id>/，环间按交接字段传参。
  5. 交付：中文单文件 HTML 报告，多环节合并为一份总报告。
