# Multi-ASIN VOC 竞品评论分析

> 💡 无 Sorftime 凭证、或调用报"额度不足"时：通过专属通道注册/充值（含 7 天试用）→ https://open.sorftime.com/home?tag=ODY2OA%7E%7E ｜ 优惠码：8668

把一类目下多个竞品 ASIN 的评论变成「谁能打、打哪里、凭什么、怎么验证」的可审计作战报告。
核心不是主题频次，而是 **ASIN-first 差异**：每个结论都必须挂到具体竞品 ASIN、具体能力维度、
可回溯的评论原声和可执行的验证阈值。

## 何时使用 / 何时不用

- 使用：用户给出品类名或一批 ASIN，要求评论分析、VOC、差评根因、竞品强弱、击破打法、A/B 测试队列、市场机会。
- 不使用：只需单 ASIN 摘要、只需翻译评论、或没有评论数据却要求编结论（此时明确说明拿不到并给替代方案）。

## 输入

- 必选：产品品类名（如 GPS wireless dog fence）、站点（默认 US）、代表 ASIN 或 ASIN 清单（8-12 个为宜）。
- 可选：用户提供的评论文件（SellerSprite 导出 / CSV / JSON）、关键词月销量、类目节点。
- 数据源优先级：用户提供的数据 → Sorftime MCP（`product_reviews` / `product_search` 等，跨 ASIN 用循环）→ 权威公开来源 → 明确标注的估算。拿不到就写"数据缺失"，绝不编造。

## 铁律（违反即返工）

1. 负向=1-3★，强负向=1-2★，正向=4-5★；全报告口径一致并在数据范围说明中写明。
2. 每个攻击主张必须同时有：目标 ASIN 的 1-3★ 负面原声 + 强位/标杆 ASIN 的正向证明 + 分差 + proof gap。证据不闭合的主张只能"观察/补 proof"，不能直接上线。
3. 不把「持平能力」包装成竞品缺陷；不把「共性/标准化问题」当可击破差异；低样本 ASIN 只能观察，不能当攻击证据。
4. 同一卖点如果同时是满意来源和差评来源（正负面翻转），Listing 必须写「承诺 + 适用条件 + 失效边界」，禁止只写卖点。
5. 评论 URL/ID 缺失（SYN-* 合成 ID）时，追溯级别=受限，结论置信度一律降为 medium 并在报告里注明，不生成虚假前台链接。
6. 横向弱位 × 纵向恶化才设为优先击破窗口；只对稳定或近期恶化的缺口设触发阈值。
7. 报告中文交付；产品/ASIN 可跳转前台；所有结论可回到原始评论。

## 主流程（详见 references/pipeline.md）

1. 定范围：品类、站点、ASIN 组合（benchmark + competitors）、近 3 年窗口、类目档案。
2. 采数据：逐 ASIN 抓取窗口内评论，记录页数审计（pages_reported / fetched / missing）与 run lineage。
3. 质量闸门：覆盖率、缺页、失败 ASIN、追溯级别；不达标就不出正式结论。
4. 关键词/ASIN 分层：核心 / 相邻 / 排除（噪声）——只有核心进正式 VOC，相邻作参照，噪声进广告否词。
5. 健康总览：组合差评率、强差评率、VP 率、评分分布、单 ASIN KPI 卡。
6. 主题×ASIN 根因矩阵：按类目主题关键词字典做标题+正文匹配，输出弱位/强位/观察位。
7. 能力竞争矩阵：主题×ASIN 的正向率、失败率、能力分（0-100）、正负面原声。
8. 正负面翻转 + 评论原声簇：识别哪些卖点需要写边界。
9. JTBD 机会：7 个左右 job 的期望结果/失败瞬间/切换触发/动作，输出机会优先级与行动建议（带证据 trace 与置信度）。
10. ASIN-first 竞品击破：击破总控塔 → 缺陷差异剖面 → 差异证据台账 → 1v1 对位 → 对手定向指令 → Listing 改写包 → 击破顺序 → 主张门禁 → A/B 测试队列 → 击破资产清单。
11. 时间维度：逐年漂移判读、主题×年能力、横纵交汇与触发阈值。
12. 交付：单文件 HTML 看板（详情/精简双模式）+ 数据质量审计 + 原始评论明细（筛选/导出 CSV）。

## 交付物规范（详见 references/dashboard-html.md）

- 单文件自包含 HTML：内联 CSS + JS + base64 商品图，不依赖外部资源。
- 顶部：报告切换（详情/精简）、KPI 条、数据范围说明。
- 详情模式：ASIN 产品速览（悬停卡）、各分析面板（锚点导航）、数据质量审计、原始评论明细（分页/筛选/导出）。
- 精简模式：观察（JTBD 主任务）→ 分析（失败槽位）→ 焦点（可证明购买标准）→ 策略（动作+复验阈值），右侧同步原声证据。
- 类目档案与数据契约（详见 references/category-profile.md 与 references/schema.md）。

## 验证清单

- [ ] 每个 ASIN 评论覆盖与缺页已审计，质量闸门结论明确
- [ ] 主题匹配有原声 + matched_terms/matched_spans 可复核
- [ ] 每个攻击主张都有目标负面 + 强位正面 + 分差 + proof gap
- [ ] 低样本/观察项未伪装成攻击证据
- [ ] 正负面翻转主题写成"承诺+条件+边界"
- [ ] HTML 单文件可打开，ASIN 可跳前台，原声可回看，CSV 可导出
