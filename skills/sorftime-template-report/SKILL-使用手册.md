# Sorftime 模板报告 Skill — 1:1 还原使用手册

## 一句话说明

这个 skill 是一条完整管线：**拿到模板 HTML → Sorftime 拉数据 → Python 清洗分析 → 产出交互式 HTML 报告**。你只需给一个新模板，我就能按同样结构做任意品类的报告。

## 我会自动产出什么

### 数据层（Sorftime 真实数据）
- 类目 Top100 → 筛选出目标细分 ASIN（如上次的 57 个带灯款）
- 每个 ASIN 的 51 个月趋势（销量/销售额/价格）
- 类目 24 个月趋势
- 核心词 + 扩展词数据
- Top5 ASIN 的评论洞察（CustomersSay）

### 分析层
- **决策评分卡**：12 维度归一化 100 分制
- **季节性指数**：哪个月是旺季、同比增幅
- **12 个月预测**：Prophet 风格 + 置信区间
- **痛点聚合**：差评关键词 + 中文映射 + 占比
- **属性机会矩阵**：渗透率/GMV 占比/溢价指数/增速
- **组合机会**：形状×安装方式×供电方式等交叉分析
- **PPC 16 词**：核心大词/二级词/精准长尾 + 建议出价

### 报告层（交互式 HTML）
| 模块 | 功能 |

## 已知坑点（已修，复用时注意）

1. **template.css 可能带 `<style>` 标签** → 注入前要 strip，否则页面白底裸奔
2. **Sorftime 趋势是逐日滚动 30 天值** → 月度值必须取每月最后一天
3. **photo 字段可能是数组** → 规范化取 `[0]`
4. **macOS grep 是 BSD 版** → 交替匹配用 `grep -E`
5. **hidden tab 里的 canvas 初始 0×0** → 点击 tab 时重建图表，不是 bug
6. **注入 JSON 时 `</script>` 要转义** → 否则浏览器提前关闭 script 标签
7. **ProductRequest 最多 10 个 ASIN/批** → 大列表要分批
8. **Sorftime CLI 有 2 行 banner** → 传给 jq 前用 `tail -n +3`
