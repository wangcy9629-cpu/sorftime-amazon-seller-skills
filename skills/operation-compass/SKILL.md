### 1.2 模式判定算法

**判定公式：**

```
精品模式得分 = 资金得分×30% + 供应链得分×25% + 经验得分×20% + 团队得分×15% + 产品开发得分×10%

精铺模式得分 = 资金得分×25% + 数据分析能力×30% + 供应链响应×25% + 团队效率×20%

铺货模式得分 = 轻资产指数×35% + 上架效率×30% + 快反供应链×25% + 低成本流量获取×10%
```

**判定规则：**

```yaml
规则1: 单一模式绝对优势
  条件: 某模式得分>75% 且 与其他最高分差>15%
  输出: 推荐该模式，置信度高

规则2: 混合模式建议
  条件: 两模式分差<10%
  输出: 推荐主模式+辅助模式混合策略
  示例: "以精铺为主，精选2-3款做精品测试"

规则3: 能力不足警告
  条件: 所有模式得分<60%
  输出: 不建议入场，提示需补强维度
  建议: 给出具体的资源补强路径

规则4: 资本化建议
  条件: 资金>100万 且 供应链=D/E级
  输出: 建议考虑1P/3P混合矩阵策略
```

## 第二章：五维类目扫描系统

### 2.1 维度一：市场容量与增长趋势

**指标定义：**

```yaml
核心指标:
  类目月销量: 过去30天Top100产品销量总和
  类目月销售额: 过去30天Top100产品销售额总和
  市场增长率: 同比/环比销量变化率
  搜索量趋势: 核心关键词搜索量变化
  季节性指数: 全年销量波动幅度

Sorftime工具调用:
  - categoryReport: 获取Top100销量数据
  - categoryTrend: SalesCount趋势
  - keywordTrend: 搜索量变化

评估标准:
  优秀: 月销量>20万且增长率>15%
  良好: 月销量10-20万且增长率5-15%
  一般: 月销量5-10万或增长率0-5%
  谨慎: 月销量<5万或负增长
```

**深度分析：**

```
1. 容量验证
   - 计算市场总容量 = Top100销量 / 预估Top100占比(通常15-25%)
   - 验证是否存在长尾市场机会

2. 趋势判断
   - 增长期: 连续3个月增长，可入场
   - 稳定期: 波动<5%，需差异化突破
   - 衰退期: 连续3个月下降，避开

3. 季节性分析
   - 强季节性: 波动>100%，需精准库存控制
   - 弱季节性: 波动20-50%，可利用波峰
   - 无季节性: 全年平稳，适合长期经营
```

### 2.2 维度二：新手友好度评分

**指标定义：**

```yaml
核心指标:
  新品数量占比: 3个月内上架产品占Top100比例
  新品销量占比: 3个月内上架产品销量占比
  新品平均评论: 新品的平均评论数
  新品存活率: 上架6个月后仍在Top100的比例
  新品牌成功率: 新品牌进入Top100的比例

Sorftime工具调用:
  - categoryReport: 新品数据
  - productSearch: 筛选新品分析

评估标准:
  优秀: 新品销量占比>15%且存活率>50%
  良好: 新品销量占比10-15%且存活率30-50%
  一般: 新品销量占比5-10%或存活率<30%
  谨慎: 新品销量占比<5%，市场封闭
```

**竞争格局判断：**

```
场景1: 新品占比高+垄断系数低
  → 最佳进入时机，市场开放且有机会

场景2: 新品占比高+垄断系数高
  → 短期套利机会，但长期难生存
  → 建议: 快进快出，不做长期投入

场景3: 新品占比低+垄断系数低
  → 市场稳定，需要强产品才能切入
  → 建议: 重产品开发，做差异化

场景4: 新品占比低+垄断系数高
  → 红海市场，新品牌慎入
  → 建议: 避开或寻找细分缝隙
```

### 2.3 维度三：竞争强度与垄断分析

**三层垄断系数：**

```yaml
Listing垄断系数:

品牌垄断系数:

  阈值: <35%健康，35-55%中等，>55%红海
  解读: 反映品牌壁垒高度

卖家垄断系数:
  定义: Top3卖家销量占Top100比例
  阈值: <40%健康，40-60%中等，>60%红海
  解读: 反映卖家集中度

Sorftime工具调用:
  - categoryReport: 垄断系数数据
  - seller看板: 卖家集中度分析
```

**亚马逊自营分析：**

```yaml
自营占比评估:
  安全: <20%
  谨慎: 20-40%（避开自营主力价格带）
  危险: >40%（新进入者生存空间小）

自营策略分析:
  - 自营产品定位：高端/中端/低端
  - 自营价格策略：成本价/市场价/溢价
  - 自营质量水平：与第三方对比

应对策略:
  - 自营占比<20%: 正常进入
  - 自营占比20-40%: 选择自营未覆盖的价格带
  - 自营占比>40%: 寻找细分差异化
```

### 2.4 维度四：成本结构与盈利空间

**成本指标：**

```yaml
流量成本:
  CPC广告均价: 类目核心词平均点击成本
  阈值: <$1低，$1-2中等，>$2高

售后成本:
  退货率: 类目平均退货比例
  阈值: <5%低，5-10%中等，>10%高

物流成本:
  平均重量/体积: 影响FBA费用
  抛货占比: 影响头程成本

运营成本:
  平均评论数: 反映运营门槛
  A+页面占比: 反映视觉门槛
  视频占比: 反映内容门槛

Sorftime工具调用:
  - keywordDetail: CPC数据
  - categoryReport: 退货率、重量体积
```

**盈利模型：**

```
盈亏平衡公式:
  ACOS盈亏点 = 毛利率 × 转化率
  可承受CPC = 客单价 × 盈亏ACOS × 转化率

资金需求测算:
  首批备货资金 = 首批数量 × 采购成本
  广告测试资金 = 测试周期 × 日广告预算
  周转资金 = 月均销售额 × 回款周期
  总启动资金 = 首批 + 广告 + 周转 + 20%安全垫
```
